## Projetos em destaque

### BankAPI — Sistema Bancário REST

Aplicação backend desenvolvida para praticar engenharia de software no contexto de um sistema bancário, com foco em regras de negócio, arquitetura e persistência de dados.

O projeto utiliza Clean Architecture e Domain-Driven Design (DDD), com APIs REST em Spring Boot. Também inclui consultas SQL nativas no PostgreSQL para gerar relatórios de movimentações por conta e um ranking de contas por volume movimentado, utilizando JOINs, agrupamentos e funções de agregação.

**Principais tecnologias:** Java 21, Spring Boot, Spring Data JPA, Hibernate, PostgreSQL, H2, SQL, JUnit 5, Mockito, MockMvc, Docker, Git e GitHub Actions.

[Ver repositório](https://github.com/hugoovargas/sistema-bancario-springboot)

### AutoReport — Automação de Relatórios

Projeto em Python voltado à automação do processamento de dados comerciais, incluindo leitura de arquivos CSV, validação de registros, análise de dados e preparação de informações para relatórios em Excel.

**Principais tecnologias:** Python, pandas, openpyxl, pytest e Git.

[Ver repositório](https://github.com/hugoovargas/auto-report)

### DevTrack — Painel de Projetos e Estudos

Aplicação web criada para organizar projetos de desenvolvimento e acompanhar sessões de estudo e metas semanais. O projeto permite praticar fundamentos de frontend, manipulação do DOM e persistência de dados no navegador.

**Principais tecnologias:** HTML5, CSS3, JavaScript, LocalStorage e Git.

[Ver repositório](https://github.com/hugoovargas/devTrack)
